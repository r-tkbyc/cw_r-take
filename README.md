# プテラノドン 3D組立ビューア

ArtiosCADから出力されたVRML（WRL）を、ブラウザ上で操作・再生するテストサイトです。

## 機能

- 組立アニメーションの再生・一時停止
- 先頭から再生
- タイムライン操作
- マウス／タッチによる自由回転
- ズーム・パン
- 初期視点へ戻す
- 全画面表示
- スマートフォン向けレスポンシブ表示

## GitHub Pagesで公開する

1. このフォルダのファイルをGitHubリポジトリへプッシュします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** のSourceを **Deploy from a branch** にします。
4. 公開するブランチ（通常は `main`）と `/ (root)` を選び、**Save** を押します。
5. 数分後に表示されるURLをスマートフォンで開きます。

ビルド作業は不要です。`index.html`を含むフォルダをそのまま公開できます。

## ローカルで確認する

WRLはブラウザのセキュリティ制限により、`index.html`をダブルクリックしただけでは読み込めないことがあります。ローカルWebサーバー経由で開いてください。

Pythonがある場合は、このフォルダで次を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 使用ライブラリ

[X_ITE](https://create3000.github.io/x_ite/) をCDNから読み込んでいます。そのため、閲覧時にインターネット接続が必要です。
