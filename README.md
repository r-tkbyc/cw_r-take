# 立体恐竜パズル 3D組立ガイド

大洋印刷が主催する子供向け体験教室用の、立体恐竜パズル3D閲覧サイトです。

現在のバージョン：`1.1.0`

## 収録モデル

- スピノサウルス
- プテラノドン
- ヴェロキラプトル

トップページから恐竜を選ぶと、それぞれの組立アニメーションを表示します。

## 機能

- 組立アニメーションの再生・一時停止
- 先頭から再生
- タイムライン操作
- マウス／タッチによる自由回転
- 慣性回転なし（指を離した位置で停止）
- ズーム・パン
- 初期視点へ戻す
- スマートフォン向けレスポンシブ表示

## GitHub Pagesで公開する

1. このフォルダのファイルをGitHubリポジトリへプッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. Sourceを **Deploy from a branch** にします。
4. 公開ブランチ（通常は `main`）と `/ (root)` を選択して保存します。
5. 公開URLで右上のバージョンが`ver 1.1.0`になっていることを確認します。

ビルド作業は不要です。

## ローカルで確認する

`index.html`の直接表示ではWRLを読み込めないことがあります。ローカルWebサーバー経由で開いてください。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000/`を開きます。

## 使用ライブラリ

[X_ITE](https://create3000.github.io/x_ite/)をCDNから読み込んでいます。閲覧時にはインターネット接続が必要です。
